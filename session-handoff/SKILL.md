# Skill：会话交接（压缩成交接文档）

## 触发场景
- 用户说「交接一下」「下次接着做」「把今天的进度存下来」。
- 一个长任务要跨会话继续，或要交给别人 / 别的 AI 接手。

## 前置确认
- 保存位置默认系统临时目录（Windows 用 `%TEMP%`），不往用户工作目录里塞文件；用户指定了位置就按用户的来。
- 已有的产物（技能文件、README、提交记录）**不重复抄写**，写路径或链接即可。

## 执行步骤
1. 写清三件事：现在做到哪一步、下一步要做什么、有哪些坑和未决问题。
2. 列出「建议调用的技能」，指名下次该读哪个技能文件。
3. 去掉敏感信息（密钥、密码、个人隐私）。
4. 保存后把文件路径告诉用户。

## 常见坑
- 把整段对话复制一遍 → 太长没人看，只留决策和结论。
- 交接文档写进项目目录，污染用户工作区。
