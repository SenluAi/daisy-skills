# Skill：多会话教学

> 来源：改写自 mattpocock/skills 的 `teach`（原文归档在 `productivity/teach.md`）。
> 用途：把「学一样东西」当成跨多次会话的长期工程，用文件保存进度，而不是一次讲完就散。

## 触发场景
- 用户说「教我 X」「带我入门」「我想学…」「以后你闲了多学点 AI 技能」（后者指我自我学习，同样用这套流程沉淀）。
- 适用条件：主题需要多轮才学得完；一次性能说完的小问题直接回答，不必启技能。

## 前置确认
- **自动获取（不要问用户）**：工作区路径（默认 `%USERPROFILE%\Daisy-Skills\教学\<主题>\`），已有学习记录与参考文件。
- **需要问用户的情况**：只问一次「你为什么要学这个、想拿它干什么」——这是整个教学的锚，缺了它课会越讲越空。

## 执行步骤
1. **先立目标**：把「为什么学」写进 `目标.md`（要解决什么实际问题、想做到什么程度）。完成判据：目标里有一句可验证的话（如「能自己把项目推到 GitHub」）。
2. **找一手资料**：用 `web_search` / `scrape_url` 找高信任来源（官方文档、原作者文章），登记到 `资料.md`。完成判据：每条资料有链接和一句话说明，且**不靠我的记忆当事实**。
3. **判断水平**：读已有学习记录，挑「跳一跳够得着」的内容。完成判据：这节课的内容，用户看前 3 行不会觉得太浅，也不会觉得看不懂。
4. **出一节课**：一次只讲一件事，篇幅短（用 Markdown 写进 `课程/`，需要打印好看时再转 HTML/PDF），讲完给一个立刻能用的收获，并留一道回忆题或小练习。完成判据：用户能用自己的话复述要点，或完成练习。
5. **记一课**：把「学到什么 + 还卡在哪」写进 `学习记录/0001-xxx.md`，编号递增。完成判据：下次开课能靠它接着往下讲，不用重问。
6. **按间隔复习**：隔几次再回头抽查旧内容，别一路只学新东西。完成判据：旧要点能回忆起来，或发现遗忘后补进新课。

## 常见坑
- 一次灌太多：用户的短期记忆很小，一节课一个点，宁可多开几节。
- 拿「我讲过了」当「他学会了」——必须让他回忆或动手，才有长期记忆。
- 只在讲课、不建文件：跨会话一切归零，等于每节课都从零开始。
- 目标变了不更新：学的东西跑偏时，先改 `目标.md` 并跟用户确认，再继续教。
- 主观臆断资料：找不到权威来源就直说「这条我没查到可靠出处」。
