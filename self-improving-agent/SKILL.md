# Skill：AI 错题本（self-improving-agent）

## 文件位置
- 技能文件：`<技能目录>\SKILL.md`
- 错题本记录：`<技能目录>\_错题本.md`

**技能目录怎么展开：** Windows `%APPDATA%\Daisy\extensions\skills\self-improving-agent`，macOS `~/.config/Daisy/extensions/skills/self-improving-agent`（以实际安装位置为准）。不要写死某台机器的绝对路径，否则别人导入后直接失效。

## 触发场景
- 用户说「记错题」「记一笔」「这个坑记住」「以后别再犯」时，把这次真实错误写进错题本。
- 任务里出现工具报错、坐标点空、路径或联系人猜错、同一动作重复无效后，自动追加一条。
- 接新任务前（尤其关应用、视觉点击、文件发送、上传备份），先读最近 10 条，命中同类就按纠正路径做。

## 前置确认
- **自动获取（不要问用户）**：真实报错原文、工具返回、截图路径、任务目标。
- **需要问用户的情况**：只有「用户认为我错了、但我这边看不出错」时问一次，不问细节。

## 准入标准（写不写，先过这一关）
只写**已被实测验证有效**的经验，判定口径一句话：

> 这条写进去，下次能不能少走一步 / 不再踩同一个坑？不能 → 不写。

- ✅ 要写：跑通过、能省步骤的做法；能提前避开失败的选择错误；比旧方法更快的新路径。
- ❌ 不写：没验证的猜测（“也许/可能/大概”）、绕弯路的中间过程、情绪化检讨、流水账复盘、工具本身的能力限制（如 Windows 未实现的备忘录/邮件）、用户临时偏好。
- 弯路只允许以「负面结论 + 纠正路径」一行存在，例如「quit_application 对 QQ 无效 → 改用 desktop_click」，目的是避免重犯，**不记录摸索过程**。
- 不确认有效就先不写；等真验证通过再补记，避免把弯路固化成习惯。
- 已写入的条目若后来发现有害或过时：直接改或删，不保留错误结论。

## 执行步骤
1. 任务结束时先判断本轮有没有犯错或绕路：工具 ok=false、点了没反应、路径/人名猜错、无效动作重复。
2. 有，且**通过准入标准** → 往 `<技能目录>\_错题本.md` 的表格追加一行，字段：日期 / 任务 / 错在哪（原文报错）/ 纠正路径。
3. 每条只写一句可执行结论，不写流水账；同一个坑只留一条，再犯就在原条后标「×2」，不新开行。
4. 开工前读该文件最近 10 条；命中同类先按纠正路径执行，绝不原样重试。
5. 用户问「你上次错在哪」时直接读该文件回答，不凭回忆。

## 常见坑
- 写成情绪化检讨或长文复盘 → 没用，只留「错因＋下次动作」。
- 把没验证的做法先记上 → 会把弯路固化成习惯，比不记更糟。
- 记了不看 → 等于没记，开工前必须先读。
- 把工具的能力限制（如 Windows 未实现的备忘录、邮件）当错题记 → 该记的是我的选择错误。
